# 改造方案：将 GitHub Copilot 依赖替换为可配置 API

## 一、改造目标

原插件通过 `vscode.lm` API 调用 GitHub Copilot，不需要 API Key 但强依赖 Copilot 订阅。  
改造目标：**用户可配置任意兼容 OpenAI Chat Completions 格式的 API（URL + Key）**，不再依赖 GitHub Copilot。

---

## 二、需要修改的文件

| 文件 | 改动性质 |
|---|---|
| `client/package.json` | 新增 3 个配置项（api.url、api.key、api.model） |
| `client/src/extension.ts` | 替换 `selectModel()` 和 `handleLLMProxyRequest()` 两个函数 |
| `src/server.ts` | **无需改动**（代理接口不变） |
| `src/analyzers/llm.ts` | **无需改动**（Prompt 构造和结果解析不变） |

---

## 三、配置项设计

在 `client/package.json` 的 `contributes.configuration.properties` 中新增：

```json
"chatCustomizationsEvaluations.api.url": {
  "type": "string",
  "default": "",
  "description": "OpenAI 兼容 API 的 Base URL，例如 https://api.openai.com/v1 或本地 Ollama 地址 http://localhost:11434/v1"
},
"chatCustomizationsEvaluations.api.key": {
  "type": "string",
  "default": "",
  "description": "API Key，将作为 Authorization: Bearer <key> 发送"
},
"chatCustomizationsEvaluations.api.model": {
  "type": "string",
  "default": "gpt-4o",
  "description": "调用的模型名称，例如 gpt-4o、deepseek-chat、qwen-plus"
}
```

## 四、核心改造逻辑

### 原有调用链（需替换的部分）

```
handleLLMProxyRequest(request)
  → selectModel()               ← 调用 vscode.lm.selectChatModels()
  → model.sendRequest(messages) ← 调用 vscode.LanguageModelChat
  → 流式拼接响应文本
  → 返回 { text }
```

### 改造后调用链

```
handleLLMProxyRequest(request)
  → 读取配置 api.url / api.key / api.model
  → 若已配置 api.url + api.key：
      → callCustomAPI(request)   ← 直接 HTTPS POST，OpenAI 格式
  → 否则（向后兼容）：
      → 原 Copilot 路径（selectModel + model.sendRequest）
  → 统一返回 { text }
```

### 新增函数：`callCustomAPI`

```typescript
async function callCustomAPI(request: LLMProxyRequest): Promise<LLMProxyResponse> {
  const config = vscode.workspace.getConfiguration('chatCustomizationsEvaluations');
  const apiUrl  = config.get<string>('api.url', '').trim().replace(/\/$/, '');
  const apiKey  = config.get<string>('api.key', '').trim();
  const model   = config.get<string>('api.model', 'gpt-4o').trim();

  const body = JSON.stringify({
    model,
    messages: [
      { role: 'system', content: request.systemPrompt },
      { role: 'user',   content: request.prompt },
    ],
    temperature: 0.1,
  });

  const response = await httpPostJSON(`${apiUrl}/chat/completions`, body, {
    'Content-Type':  'application/json',
    'Authorization': `Bearer ${apiKey}`,
  });

  // 解析 OpenAI 标准响应格式
  const text = response?.choices?.[0]?.message?.content ?? '{}';
  return { text };
}
```

> **`httpPostJSON`** 复用或仿照现有的 `httpGetBuffer`，使用 Node.js 内置 `https` 模块，无需引入 axios 等依赖。

### 修改 `handleLLMProxyRequest` 分支逻辑

```typescript
async function handleLLMProxyRequest(request: LLMProxyRequest): Promise<LLMProxyResponse> {
  const config = vscode.workspace.getConfiguration('chatCustomizationsEvaluations');
  const apiUrl = config.get<string>('api.url', '').trim();
  const apiKey = config.get<string>('api.key', '').trim();

  // 优先使用自定义 API
  if (apiUrl && apiKey) {
    outputChannel.appendLine('[LLM Proxy] Using custom API: ' + apiUrl);
    try {
      return await callCustomAPI(request);
    } catch (error) {
      const message = error instanceof Error ? error.message : 'Unknown error';
      outputChannel.appendLine(`[LLM Proxy] Custom API error: ${message}`);
      return { text: '{}', error: `Custom API request failed: ${message}` };
    }
  }

  // 回退到原 Copilot 路径（保持向后兼容）
  // ... 原有逻辑不变 ...
}
```

## 五、安全注意事项

| 风险 | 处理方式 |
|---|---|
| API Key 明文存储在 settings.json | 建议文档提示用户使用 VS Code Secret Storage（可后续升级） |
| HTTPS 请求需校验证书 | 使用 Node.js `https` 模块默认行为，不跳过证书验证 |
| 超时 | 沿用原有 `LLM_REQUEST_TIMEOUT_MS = 30_000` |
| 请求体注入 | Prompt 内容已由 `llm.ts` 做了 XML 标签隔离，此处无额外风险 |

---

## 六、改造范围总结

```
改动最小化原则：
  ✅ 语言服务器端（src/）完全不动
  ✅ Prompt 构造逻辑（llm.ts）完全不动
  ✅ 诊断转换逻辑完全不动
  ✅ 向后兼容：未配置 api.url/key 时仍走 Copilot
  ✅ 仅替换 extension.ts 中的 handleLLMProxyRequest + 新增 callCustomAPI
  ✅ 仅在 package.json 中增加 3 个配置项
```

## 七、用户配置示例

用户在 VS Code `settings.json` 中配置：

```json
{
  "chatCustomizationsEvaluations.api.url":   "https://api.deepseek.com/v1",
  "chatCustomizationsEvaluations.api.key":   "sk-xxxxxxxxxxxxxxxx",
  "chatCustomizationsEvaluations.api.model": "deepseek-chat"
}
```

或本地 Ollama：

```json
{
  "chatCustomizationsEvaluations.api.url":   "http://localhost:11434/v1",
  "chatCustomizationsEvaluations.api.key":   "ollama",
  "chatCustomizationsEvaluations.api.model": "qwen2.5:14b"
}
```
